# Simulated SIR household data

Individual-level outcomes simulated from a basic
susceptible-infected-recovered (SIR) model for 500 households. Everyone
starts susceptible, the daily extra-household infection probability is
1%, and the daily intra-household infection probability is 5%. Each
individual has two binary observations: one informative about active
infection (e.g. a PCR test) and one informative about recovery (e.g. an
IgG antibody test).

## Usage

``` r
sir
```

## Format

A data frame with one row per individual per day and the following
columns:

- t:

  Day of observation.

- part_id:

  Participant identifier within the household.

- enroll:

  Enrollment indicator (1 = enrolled, 0 = not enrolled).

- state:

  True latent compartment (1 = S, 2 = I, 3 = R).

- hh_size:

  Household size.

- hh_id:

  Household identifier.

- pcr:

  Binary outcome informative about active infection.

- igg:

  Binary outcome informative about recovery.
