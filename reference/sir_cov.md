# Simulated SIR household data with covariates

Individual-level outcomes simulated from a basic SIR model for 500
households, together with two binary individual-level covariates that
affect the intra- and extra-household infection probabilities. Used to
demonstrate fitting covariate effects.

## Usage

``` r
sir_cov
```

## Format

A list with two elements:

- observations:

  A data frame of outcomes with the same columns as
  [`sir`](https://accidda.github.io/hestia/reference/sir.md).

- covariates:

  A data frame with one row per individual and two binary covariate
  columns, `x1` and `x2`.
